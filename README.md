# paper-daemon public site

Public home for tested OSS, automation field notes, build receipts, service proofs and lightweight tools.

The site is intentionally evidence-first: public claims should point back to code, tests, reproducible examples, or verified delivery receipts instead of vague capability lists.

## Publishing rule

Public pages should make it easy to answer four questions:

1. What problem does this solve?
2. What can it actually do today?
3. What evidence exists?
4. What is explicitly out of scope?

OSS and paid offers should not rely on unsupported claims, hidden affiliate influence, fake usage stories, or results that have not been verified.

## Repository role

This repository contains the public site source and distribution pages. Production AgentLink internals, credentials, private operational state and customer data do not belong here.

## Quality bar

Before a tool or service is promoted from this site, prefer:

- a specific one-line purpose
- a usable README or landing page
- a concrete quick start or buying scope
- explicit safety / privacy / non-goal boundaries
- automated tests or another reproducible verification path when applicable
- working public links with no stale ownership or product naming

Small tools can stay small. They should not look unfinished.
