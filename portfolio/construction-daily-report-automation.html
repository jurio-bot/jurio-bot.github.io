建設日報を、CSVからまとめる。

完全に架空の現場データを使った小さい制作デモ。CSVの必須列を確認して、日付ごとの作業人数と平均進捗を集計し、集計CSVと日本語の日報を生成します。

この公開版では変換処理をPythonで実行済み。Claude Code本体を操作して生成した実績とは書いていません。Claude Code / MCP / APIから同じ処理を呼べる形を意識して分離しています。
