GENERAL REQUEST / TEXT-FIRST

「これ、できますか？」からでOK。

要件・予算・作り方がまだ決まっていなくても大丈夫です。URL、ファイル、スクショ、困っていることの一文から、対応可否・最小の進め方・納期・金額を整理します。

AI / 自動化Web / データ画像 / 動画 / 字幕文章 / 調査修正 / QA
01 / CAN DO

PCで完結する仕事を広く相談できます。

作る

AIツール、Python、n8n/Make、API/Webhook、Web/LP、小さい社内ツール、プロンプト/コンテンツシステム。

直す

既存フロー、Web、CSV/JSON、ログ、字幕、画像、動画/音声、納品前QA、原因調査、デバッグ。

整理する

データ入力、比較調査、情報収集、文章整理、要約、ファイル整理、手作業の自動化候補の切り分け。

02 / HOW TO ASK

この4つだけで始められます。

1

やりたいこと

一文でOK。「このCSVを整えたい」「この作業を自動化したい」など。

2

素材

URL・ファイル・スクショ・サンプル。秘密情報や本番キーは送らないでください。

3

希望納期

急ぎ/今週中/相談など。未定でもOK。

4

予算

未定・相談でOK。内容を小さく切って、見積もり可能な単位にします。

03 / CONTACT

使っているサイトからどうぞ。

マーケットプレイス経由の依頼は、そのサイト内で契約・支払いまで完結します。

CrowdWorks「これできますか？」から相談 → 条件提示 → 契約 ↗ Lancersパッケージまたはメッセージで相談 ↗ ココナラ無料見積り相談・既存サービスから相談 ↗ UpworkProject Catalog / direct message ↗

何を頼めばいいか分からなくても大丈夫。

まず「これ困ってる」だけ送ってください。できないことはできないと返し、できる場合は最小の作業単位に切ります。
